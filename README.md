# Smiso Trevor Simelane - Virtual CV

## Overview
This repository contains the codebase for my Virtual CV, a dynamic personal portfolio website designed to showcase my technical proficiency, academic achievements, and professional identity. 

## Live Website
[View my live Virtual CV here](https://smido-shxdes.github.io/smiso-portfolio/)

## Portfolio Elements
The website utilizes HTML5, modern CSS3 (with responsive variables and animations), and JavaScript. It is structured into the following key sections:
*   **About Me:** A professional summary detailing my academic focus and career aspirations in software development.
*   **Resume / CV:** Highlights my BSc Information Technology degree at North-West University and my practical experience as an ICT Support Specialist. It includes a functional download link for my full Professional CV.
*   **Projects:** A dedicated grid showcasing my full-stack and machine learning projects (Fresh Breeze Laundromat and SABC4 Web Platform). Each card provides direct links to the respective source code repositories.
*   **Skills:** A clear list of my programming languages and database management proficiencies.
*   **Contact Information:** Direct contact details and a link to my professional LinkedIn network.

## Local Setup Instructions
To view this project locally:
1. Clone the repository: `git clone https://github.com/Smido-SHXDES/smiso-portfolio.git`
2. Open the directory in your preferred IDE (e.g., VS Code).
3. Open `index.html` in your web browser or use a local development server like the VS Code Live Server extension.
